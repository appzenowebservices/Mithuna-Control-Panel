# Mood Board Template

## Structure
- **Color Palette**: Primary, secondary, accent colors
- **Typography**: Font families, sizes, weights
- **Imagery**: Reference images, textures, patterns
- **Layout**: Grid systems, spacing, alignment
- **Components**: Buttons, forms, cards, navigation

## Usage
```bash
# Create new mood board
/create-moodboard "project-name"

# Add assets
/add-asset --type=image --source=figma --id=12345

# Generate style guide
/generate-styleguide
```

## Integration Points
- Figma API for importing designs
- Adobe XD for prototyping
- Blender for 3D elements
- Local file system for asset storage
