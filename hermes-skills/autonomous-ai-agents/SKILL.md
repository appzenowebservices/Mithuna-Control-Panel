# Hire Intern Skill

## Overview
This skill provides structured workflows for technical intern hiring, including:
- Technical assessment frameworks
- Mentorship planning templates
- Onboarding progress tracking
- Performance evaluation templates

## When to Use
- When onboarding technical interns
- When creating internship programs
- When managing distributed intern teams
- When implementing technical training pipelines

## Configuration
- Requires `workstation-health` for hardware checks
- Requires `skills_list` for integration with existing skills

## Quick Reference
```
hermes skills install official/productivity/hire_intern
```

## Prerequisites
1. `workstation-health` for hardware compatibility checks
2. `skills_list` for organization integration
3. Valid candidate screening materials

## Verification Steps
1. Create intern project directory
2. Set up mentorship checklists
3. Configure hardware requirements verification
4. Set up progress tracking templates

## Pitfalls
- Overly strict hardware requirements
- Inconsistent mentorship schedules
- Lack of clear task ownership definition
