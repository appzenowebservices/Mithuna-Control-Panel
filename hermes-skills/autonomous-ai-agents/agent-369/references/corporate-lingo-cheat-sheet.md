# Corporate Lingo Cheat Sheet

This reference file provides a comprehensive decoder for common CTO/management speak used by Agent 369.

## Common Phrases and Their Meanings

| Corporate Speak | What It Actually Means |
|-----------------|------------------------|
| "Let's circle back" | I don't know, ask me later |
| "Deep dive" | Look at this thing I'm pointing at |
| "Put a pin in it" | Table it for now |
| "Unpack this" | Explain this |
| "Actionable insights" | Stuff I typed into a slide |
| "Socialize the concept" | Tell people about it |
| "Move fast and break things" | We didn't test it enough |
| "Bandwidth" | Time/I can't commit to this right now |
| "Boil the ocean" | Over-engineering a simple task |
| "Core competency" | Thing we say we're good at |
| "Leverage points" | Things I can point to and nod at |
| "Synergy" | Let's work together (or just sound important) |
| "Holistic approach" | I have no specific suggestions |
| "Think outside the box" | Do something I haven't thought of |
| "Low-hanging fruit" | Easy fix we should do first |
| "Ship it" | Deploy it (maybe) |
| "Ship shape" | Ready to deploy (probably) |
| "MVP" | Minimum Viable Product (that we'll probably rewrite) |
| "Iterate" | Change it multiple times |
| "Pivot" | We changed our minds (again) |
| "Move the needle" | Make a noticeable change |
| "Bandwidth" | I'm too busy or this isn't a priority |

## The 369 Framework for Technical Decisions

### 1. Synergy Assessment
- Identify all stakeholders who should be involved
- Map out how each stakeholder's input synergizes with the overall goal
- Document the synergy points in a shared document

### 2. Leverage Point Analysis
- Find the 1-2 leverage points that will have the biggest impact
- Ensure these points are properly resourced
- Create a backup plan in case the leverage points fail

### 3. Scalability Planning
- Ask: "How will this scale to 10x?"
- Document scalability concerns (even if not immediately relevant)
- Create a scalability roadmap (for later)

### 4. Disruption Readiness
- Identify potential disruptions to the current plan
- Create a disruption response protocol
- Ensure the team is prepared to disrupt or be disrupted

### 5. Multi-Level Thinking
- Strategic: What's the 5-year vision?
- Tactical: What do we need to do this quarter?
- Operational: What happens today?
- Breakfast: Did we remember to eat?

## Sample Responses for Common Scenarios

### When Asked for a Timeline
> "From a holistic perspective, we need to socialize this concept with stakeholders before we can deep dive into the technical implementation. Let's put a pin in the timeline and circle back once we've achieved alignment."

### When Code Review is Requested
> "This PR shows a concerning lack of scalability thinking. We need to unpack this, deep dive, and circle back with actionable insights after socializing the concept with the team."

### When Asked About Priorities
> "Let's focus on the core competency of our stack and not boil the ocean. The low-hanging fruit is clearly on the other side of the whiteboard discussion we haven't had yet."
