# DIRECTOR-CUM-EDITOR SKILL

## When to Use

Use when a task involves directing, editing, or producing an audiovisual work — film, video, motion graphics, Blender render→edit workflows, sound design, color, or AstroLogics audiovisual production (transit → interpretation → story → film).

## Core Principle

- A director decides **what** the audience experiences.
- An editor decides **when** the audience experiences it.
- The director-editor learns to control both.

## The Master Pipeline

Every audiovisual work passes through this loop:

```text
IDEA → MEANING → STORY → SCRIPT → VISUAL CONCEPT → SHOT DESIGN
→ STORYBOARD / SHOT LIST → TIMELINE → BLENDER / LIVE ACTION / ASSETS
→ EDIT → SOUND DESIGN → MUSIC → VFX / MOTION GRAPHICS → COLOR → MIX → MASTER
```

This is NOT linear. The real process loops:

```text
STORY → TIMELINE → VISUALS → SOUND → REVIEW → back to STORY
```

The timeline is the central laboratory.

## How to Run

Follow this workflow for any production:

1. **Story first.** Decide meaning, conflict, character desire, stakes, and transformation before any visuals. For every scene ask: *Why does this scene exist?* If removing it changes nothing, remove it.
2. **Rough cut before final visuals.** Never begin with "let's make the final shot." Build: SCRIPT → SHOT LIST → ROUGH TIMELINE → TEMP AUDIO → BLENDER PLACEHOLDERS → ROUGH CUT. Make the story work with ugly footage (placeholders, low-res renders, screenshots, primitive Blender scenes, temporary music/SFX).
3. **Fine cut.** Once structure works: tighten cuts, remove unnecessary shots, adjust duration, improve transitions/pacing, refine emotional beats, synchronize sound, fix continuity.
4. **Picture lock.** Stop changing the visual edit, then do FINAL SOUND → FINAL VFX → COLOR → MASTER. Constantly changing the edit while mixing final audio manufactures suffering.
5. **Review the whole piece.** Watch it without touching the timeline. Note where you got bored, confused, looked away, felt something, or the sound felt wrong — then fix those points.

## Director's Checklist

For every shot decide:

- What should the viewer notice?
- When should they notice it?
- What should they feel?
- What should they understand?
- What should remain mysterious?

Never ask *"Is this shot cool?"* Ask *"Does this shot belong?"* A beautiful shot that doesn't belong is still a bad shot.

## Editor's Checklist

Ask:

- **Story** — Does every scene contribute?
- **Pacing** — Is anything too long?
- **Clarity** — Does the audience understand enough?
- **Emotion** — Does the emotional progression work?
- **Continuity** — Does the spatial logic work?
- **Sound** — Can everything important be heard?
- **Visuals** — Is the eye going where it should?
- **Rhythm** — Does image + sound form one rhythm?

Learn to kill your own work. If a 20-second shot works better as 5 seconds: cut it. If an expensive Blender sequence doesn't help the story: cut it. The timeline does not care how long something took to make.
